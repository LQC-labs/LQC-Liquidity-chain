# LQC Canonical Tokenomics Baseline

Status: **Architecture Freeze canonical baseline**

This file is the repository-level source of truth for tokenomics reconciliation during Architecture Freeze. Historical drafts remain Git audit history but are superseded and must not be used for current whitepaper, website, development, vesting, circulating-supply, or CEX evidence.

## Fixed supply and TGE

- Fixed total supply: **1,000,000,000 LQC**
- Planned TGE circulation: **150,000,000 LQC (15%)**

## Superseded historical values

Earlier draft values, including a 300M initial-circulation concept, a 3.8% investor allocation concept, or earlier vesting variants, are **not current project policy** and must not be reintroduced into current documents or implementation unless governance explicitly approves a new tokenomics revision.

## Staking consistency

LQC Staking does not increase the fixed supply. Token-denominated staking rewards must come from a disclosed, governance-approved existing allocation and reconcile to on-chain balances and circulating-supply reporting. Revenue-funded rewards are accounted separately and are not guaranteed yield.

## CEX consistency gate

Before CEX submission, the whitepaper, website, token contract, vesting contracts, allocation register, circulating-supply methodology, staking reward budget, market-making inventory, and exchange application must reconcile exactly to this canonical baseline or to a later explicitly approved version that supersedes it.
